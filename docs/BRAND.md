# Fafnir brand guide

## Name

- Product name: **Fafnir**
- Descriptor: **Asset Stack Manager**
- Full lockup: **Fafnir — Asset Stack Manager**

「Asset Manager」だけではファイル整理ツールに見えるため、所有アセットから実装構成を
組む中核機能を示す `Asset Stack Manager` を正式なdescriptorにします。

## Logo variants

| Variant | File | Use |
| --- | --- | --- |
| Primary lockup | [`fafnir-header-logo.png`](../game_stack_planner/static/fafnir-header-logo.png) | README、製品紹介、横長header |
| Text wordmark | HTML/CSS | 小さいapp headerや、primary lockupを判読できない幅で使用 |
| Flat Geometry | [`fafnir-logo-flat.svg`](../game_stack_planner/static/fafnir-logo-flat.svg) | faviconや小型表示を検討するときの比較候補。正式採用ではない |

ブラウザで `/brand.html` を開くと残っている図形候補を確認できます。

Rune Vault、グラフィティ、2Dカートゥーンは不採用としました。
完成案として扱わず、必要になった場合は専用のアートディレクションと作画工程を別途設けます。

Primary lockupには周囲の余白を残し、縦横比を変更しません。暗い背景を前提とするため、
白背景や小型表示ではtext wordmarkを使用します。
